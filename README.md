## How it is built

- A single `index.html` file with inline CSS and JavaScript. No framework and no build step.
- The 3D animations are drawn on HTML canvas with a small hand-written 3D projection, so no 3D library is used.
- Fonts come from Google Fonts: Bricolage Grotesque, Hanken Grotesk and JetBrains Mono.
- Light and dark mode follow the system setting.
- Works on phone and desktop. Animations stop for people who have "reduce motion" turned on.

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

```bash
git clone https://github.com/amish822125/MyPortfolio.git
cd MyPortfolio
# then open index.html in your browser
```

## Deployment

The site is hosted with GitHub Pages from the `main` branch, root folder. Any change pushed to `main` goes live in a minute or two.
