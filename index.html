CineMatch, a movie recommendation system

Pick a movie and get similar ones. Matches are ranked by how close the movies' text data is, so the app does not need other users' ratings.

  • Built a content-based recommender using TF-IDF and cosine similarity on a TMDB movie dataset, with a Flask backend and an HTML, CSS and JavaScript frontend.
  • Fixed data problems such as data-type mismatches, duplicate titles and case-sensitive search, which made results more reliable.
  • Added live search, genre filters, a mood picker, trailers, favorites saved in the browser, and a stats dashboard with charts.
  • Fetched posters from the TMDB API in parallel threads with an in-memory cache, so movie grids load without waiting on each request.
  • Deployed the application on Render with a redesigned frontend.

How CineMatch works

  1. Prepare once

    The movie dataset and its TF-IDF vectors are saved as files and loaded when the app starts, so nothing is rebuilt on each request.

  2. Compare

    For the chosen title, matched without caring about case, the app scores every movie with cosine similarity, skips the movie itself and returns the top 8 with a match percentage.

  3. Show

    Posters come from the TMDB API, fetched with 10 threads and cached in memory. If a lookup fails, the card still loads without a poster.
